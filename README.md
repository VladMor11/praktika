Тестовый проект проверяет следующие основные сценарии:

•	Загрузка сайта — проверка успешного открытия главной страницы сервиса Яндекс Маркет

•	Работа поиска — проверка корректной работы поисковой строки и выполнения запроса пользователя

•	Отображение результатов — проверка наличия результатов после выполнения поискового запроса

•	Навигация по сайту — проверка перехода на страницу карточки товара при выборе элемента из списка
