Тестовый проект проверяет следующие основные сценарии:

• Успешную загрузку главной страницы Яндекс Маркет;
• Работоспособность поисковой строки;

• Навигацию по категориям сайта;

• Открытие карточки товара и наличие основных элементов (включая кнопку «В корзину»);

• Обработку и закрытие cookie-баннера.

Быстрый запуск:

Установите Python 3.8+

Установите зависимости:

pip install selenium==4.15.0
